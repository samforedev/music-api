# 🎵 Music API

A **Node.js** and **TypeScript** backend API for managing **musical bands**, their members, albums, and songs, following the **MVC architecture**.

## 🚀 Features

- 🟢 **Node.js** + **Express** backend
- 🔹 **TypeScript** for type safety
- 🔹 **MVC architecture** (Models, Routes (Views), Controllers)
- 🔹 **Environment-based configuration** using **dotenv**
- 🔹 **Database integration** (**MongoDB**)
- 🔹 **Docker & Docker Compose** for deployment
- 🔹 **RESTful API** for managing bands, members, albums, and songs
